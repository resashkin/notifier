Add an Android 11+ phone over Wi-Fi (pairing code)
  1. Phone and Mac on the same Wi-Fi.
  2. Phone: Settings → About phone → tap Build number 7× to enable Developer options.
  3. Developer options → Wireless debugging → on → Pair device with pairing code.
  4. Enter the IP:port and 6-digit code shown there, press Pair.
  5. Back on the Wireless debugging screen, enter the IP:port shown under IP address & Port, press Connect.
